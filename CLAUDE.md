# Instrucciones del repositorio

La guía canónica para agentes de este proyecto es [`AGENTS.md`](AGENTS.md): léela antes de cambiar código o datos. Ahí están el mapa del repositorio, límites de publicación, cuidados de privacidad, comandos de verificación y criterios para elegir skills.

Las skills locales están indexadas en [`.agents/skills/README.md`](.agents/skills/README.md). Carga solo las pertinentes a la tarea; no copies ni instales skills externas sin revisar procedencia, licencia y necesidad.
