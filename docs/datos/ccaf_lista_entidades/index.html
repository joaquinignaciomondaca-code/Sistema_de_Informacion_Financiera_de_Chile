Esquema y consulta

La tabla contiene 22 columnas; el esquema JSON enlazado arriba es la definición completa. La consulta se ejecuta en el navegador con el motor del sitio, no mediante SQL remoto.

SELECT rut_completo, razon_social, estado_vigencia FROM ccaf_lista_entidades ORDER BY razon_social;

Abrir esta consulta en el explorador; se ejecutará en tu navegador.
