Qué puedes consultar

La cartera mensual permite examinar instrumentos de renta fija, acciones y cuotas de fondos mutuos, inversiones extranjeras y bienes raíces. El registro de entidades ayuda a identificar qué compañías reportaron y qué periodos están disponibles.

La cobertura depende del archivo: algunas series comienzan en 2016 y otras tienen una historia más corta. Cada fila del catálogo indica su periodo publicado, número de registros, descripción y enlace al manifiesto de descargas.

Cómo leer los montos

Las unidades y definiciones siguen el archivo de origen y se explican por conjunto. No se convierten automáticamente monedas ni se homogeneizan criterios contables entre formularios. Antes de comparar periodos o compañías, revisa el corte, el campo de valorización y las notas del esquema.

Este sitio es un proyecto independiente que organiza datos públicos; no es una publicación oficial de la CMF y no entrega recomendaciones de inversión.

Consultar estos datos con Python y DuckDB

También puedes encontrar la tabla de renta fija, revisar sus columnas y agrupar los valores reportados con el SDK de SIF. La guía paso a paso para consultar carteras de seguros con Python incluye el código, las unidades, la fuente y los límites de interpretación.

API y descargas

Los datos están disponibles como archivos estáticos y pueden utilizarse desde Python, DuckDB u otras herramientas compatibles con Parquet. El catálogo API describe los objetos y sus recursos; los manifiestos de cada conjunto enumeran los archivos y periodos.
