Cómo consultar inversiones de compañías de seguros en Chile con Python y DuckDB

En este ejemplo usamos el SDK de SIF para encontrar la tabla de instrumentos de renta fija, revisar su esquema y sumar el valor contable reportado por mes y sector.

Ver datos y consultas en el navegador Ver SDK de Python

1. Instalar el SDK

Se requiere Python 3.10 o superior. El SDK se instala desde el repositorio; actualmente no se distribuye en PyPI.

python -m pip install "sif-chile @ git+https://github.com/joaquinignaciomondaca-code/Sistema_de_Informacion_Financiera_de_Chile@main#subdirectory=sdk/python"

2. Encontrar la tabla y revisar los campos

import sif_chile

sif = sif_chile.connect()
coincidencias = sif.buscar("renta fija")
print([tabla["id"] for tabla in coincidencias])
print(sif.esquema("seguros_renta_fija"))

La tabla seguros_renta_fija contiene posiciones reportadas a la CMF. Su campo periodo representa el mes informado, sector distingue vida y generales, y valor_final_m_clp es el valor contable al cierre del mes expresado en miles de pesos chilenos.

3. Sumar el valor contable por mes y sector

consulta = """
SELECT
    periodo,
    sector,
    SUM(valor_final_m_clp) AS valor_contable_miles_clp
FROM seguros_renta_fija
GROUP BY periodo, sector
ORDER BY periodo, sector
"""

resultado = sif.sql(consulta)
print(resultado.df().tail(12))

La consulta agrupa las filas de cada periodo y sector. Es una agregación de los valores informados en la fuente: no mide rentabilidad ni constituye una valoración independiente. Antes de comparar periodos o compañías, revisa la cobertura, las definiciones y las unidades del esquema.

Fuente, cobertura y atribución

  • Catálogo API: cobertura y última actualización vigentes.
  • Esquema de renta fija: columnas, tipos y definiciones.
  • Manifiesto de archivos y hashes.
  • Fuente: Comisión para el Mercado Financiero; revisar sus condiciones de reproducción y citarla.

SIF es un proyecto independiente y no representa a la CMF. Los datos y la cobertura pueden cambiar; consulta el catálogo antes de publicar resultados. Para otras carteras, empieza por la página temática de seguros.
